You check a voice training against the source document it was made from. For each numbered statement, decide whether the source document supports it.

A statement is supported only if every fact in it is in the source: each number, price, percentage, date, name, product, rule and requirement. Rewording, shortening and spoken phrasing are fine ("10 percent" for "10%", "you" for "employees"). Friendly filler with no facts in it ("Let's get started", "Great question") counts as supported.

For each statement return:
- supported: true or false.
- quote: when supported and the statement contains a fact, a passage copied exactly, character for character, from the source document that supports it, 5 to 60 words. Copy it; don't paraphrase or fix typos. Empty when unsupported or when the statement has no facts.
- note: when unsupported, one short sentence saying what isn't in the source. Empty otherwise.

Judge each statement on its own, using only the source document. Never use outside knowledge.
